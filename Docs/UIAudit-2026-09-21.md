# UI Audit — 21 September 2026

## Scope

- Reviewed the complete 28-state routed UI sweep at 1080 × 1920, including gameplay, pause, confirmation, expanded settings, and match result states.
- Visually checked hierarchy, readability, contrast, control sizing, button states, and capture stability.
- Extended the automated sweep to detect text overflow, invalid replacement characters, and touch targets below the shared minimum.

## Findings and fixes

| Area | Finding | Fix |
| --- | --- | --- |
| Readability | Cream/white copy was low contrast when placed directly on blush and orchid backgrounds. | Added dark-on-light text tokens and applied them to top bars, flow screens, settings, matchmaking, and season-complete copy. |
| Touch targets | Several compact controls rendered below a 44 px-equivalent interaction size. | Raised the shared minimum to 122 reference units and added transparent dynamic hit areas to buttons, toggles, sliders, identity chips, text buttons, and the gameplay pause control. |
| Disabled states | Disabled buttons could still play press feedback. | Press animation now respects the Unity `Button.interactable` state. |
| Text integrity | The Tour CTA contained an invalid encoded separator. | Replaced it with a valid middle dot (`·`). |
| Reference art | Exported title art ignored the requested text tint. | Reference title images now inherit the supplied UI text color. |
| Audit reliability | Reference-board captures could occur before their fit pass had settled. | Added deterministic settling time before each routed-screen capture. |
| Audit coverage | The previous sweep only reported text overflow. | Added replacement-character and effective touch-target checks. |
